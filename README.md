# orchestra-mcp/pack-native-kotlin

Kotlin and Android native plugin development agents

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-native-kotlin
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-native-kotlin")
```
